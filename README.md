# HR Analytics Dashboard

An interactive HR Analytics Dashboard built using Microsoft Power BI to analyze employee data and provide clear insights into workforce performance.

## 📊 Project Overview

This project focuses on analyzing HR data to understand employee distribution, salaries, performance, tenure, employment status, and employee turnover across different departments.

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Visualization

## 📌 Key KPIs

- Total Headcount
- Average Salary
- Average Performance
- Average Tenure
- Active vs. Terminated Employees

## 📈 Dashboard Analysis

The dashboard includes:

- Employment Status Analysis
- Headcount by Department
- Average Salary by Department
- Terminations by Department
- Date-based Employee Analysis

## 🎛️ Interactive Filters

Users can interact with the dashboard using:

- Department
- Education
- Employment Status
- Date

These filters allow users to explore the HR data from different perspectives.

## 🎯 Project Objective

The main objective of this project is to transform HR data into an interactive dashboard that makes important workforce insights easy to understand and supports data-driven decision-making.
